# Qkart-backend-node
- Frontend is deployed on Netlify: https://fullstack-qkart-node.netlify.app
- Backend is deployed on Render: https://qkart-backend-node-q7rw.onrender.com/v1
- The backend typically takes up to a minute to boot, as it doesn’t receive requests frequently.
### A backend project made using Express, Node and Mongodb.
#### How to run this project?
- clone the project using git clone or download the zip.
- just do a *npm install* to install the necessary packages.
- after node_modules is installed just run *npm start* command.
